# Sri Rajan Photography
Premium multi-page photography studio website built with Next.js.

## Local preview
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Pages
- `/` — Home
- `/portfolio` — Filterable portfolio
- `/services` — Photography and film services
- `/albums` — Albums, frames and wall art
- `/contact` — Booking enquiry
- `/stories/vishnu-kaviya` — Example editorial wedding story + lightbox

See `PASS3_NOTES.md` for the latest changes.
