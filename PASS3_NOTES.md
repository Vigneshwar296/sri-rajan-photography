- Supplied gold crown monogram integrated as the primary Sri Rajan Photography logo
- Cinematic branded loading screen
- Stronger premium gold/black brand treatment
- Improved desktop and mobile navigation
- Cinematic hero motion and reveal effects
- Scroll-reveal interactions
- Portfolio category filtering
- Portfolio hover interactions
- Wedding-story gallery lightbox
- Previous / next / close lightbox controls
- ESC-key lightbox closing
- Refined buttons, links and card micro-interactions
- Responsive interaction improvements
- Services, Albums & Frames, Contact and Story pages retained

## Photography
The layouts are built so stock photography can be used now and replaced later with Sri Rajan Photography's real work without redesigning the pages.

## How to run
1. Extract this ZIP.
2. Open Terminal.
3. Type `cd ` including the space.
4. Drag the extracted `sri-rajan-photography-pass3` folder into Terminal and press Enter.
5. Run `npm install`.
6. Run `npm run dev`.
7. Open http://localhost:3000
